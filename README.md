# Jarvis — Tony MVP v40

**Ready to reinstall: September 13, 2026. Use the install command, not a DMG. Do not uninstall first.**

## Install or reinstall

1. [Download Jarvis-Tony-MVP.zip](https://github.com/JT5D/jarvis-releases/releases/download/tony-mvp-v40/Jarvis-Tony-MVP.zip).
2. Unzip it, open `mvp-demo`, and double-click **Install Jarvis.command**. Keep the `app` folder beside the command.
3. Press Return to keep your saved OpenAI API key when prompted. Jarvis opens automatically.

Your existing Keychain key, profile, and memories are preserved. No DMG is needed.

Ask **“How do you spell cat?”** or **“What happened with Anthropic in the news today?”** For voice, press **Start voice** and allow microphone access if prompted.

## What was verified

The exact v40 package passed legacy checks/tests, server startup/self-test, and rendered browser checks. Live OpenAI checks covered spelling, current news with sources, historical Firefox versus current perception, explicit blindness, realtime answers, and browser voice-session creation. ## Rollback

Double-click **Roll Back Jarvis.command** in the same folder. It restores the previous app and pauses automatic updates while preserving your key and profile. Reinstall v40 to resume updates.
